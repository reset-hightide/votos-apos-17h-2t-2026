# Votos após as 17h — 2º turno 2026

Dashboard em HTML com os votos registrados depois das 17h no 2º turno das eleições presidenciais de 2026 (25/10/2026), quando o STF prorrogou a votação até as 19h.

**Versão 1:** dados nacionais, a partir de reportagens que usam dados do TSE. O recorte por estado e município ainda não existe, porque o TSE não publicou os logs de urna do 2º turno.

**Versão 2 (planejada):** detalhamento por UF e município, calculado a partir dos logs de urna, assim que forem publicados.

Página: https://reset-hightide.github.io/votos-apos-17h-2t-2026/
